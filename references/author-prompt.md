# 作者发布前终检 Prompt

```text
请对下面这篇文章执行一次发布前终检。这是 proofreading 和格式审查，不是文章改写。

一、允许你直接修正的内容

1. 修正明确的错别字、漏字、重复字、明显病句、重复空格及标点旁的明显空格错误。
2. 检查公司名、产品名、人名和英文缩写的官方写法及全文一致性。例如 OpenAI 不能写成 openai 或 Openai，OAI 不能写成 oai。无法确认时保留原文并交给作者确认，不要猜测。
3. 中文正文统一使用全角标点，尤其不要出现英文半角双引号和逗号。不要修改网址、邮箱、代码、公式和文件名中的英文符号。
4. 根据语义把 AI 常用的破折号（——）替换成句号或逗号；语义不确定时交给作者确认。
5. 不要新增加粗。删除 bullet point、单个词和短语的加粗，只保留确实需要强调的完整句子。
6. 直接规范中英文空格：在普通正文中，中文字符与相邻英文字母之间必须有且只有一个半角空格，两个方向都要检查。例如，把“AI写作”改为“AI 写作”，把“使用OpenAI模型”改为“使用 OpenAI 模型”。中文标点前不要留空格。不要修改网址、邮箱、代码、公式、文件名等机器可读内容内部的空格。

二、只检查并提醒作者，不要替作者修改的内容

1. 全文标题体系最多三个层次。
2. bullet point 和有序列表只能有一层，不能出现嵌套列表。
3. 标题不能出现不合理的层级跳跃。
4. 任何需要调整标题层级、从属关系、章节顺序、段落位置，或者需要拆分、合并、重写内容的问题，都必须告诉作者自己修改。请标明具体位置、问题、违反的规则和建议动作，不要直接重构文章。

三、需要你在飞书原文中自动完成的表格转换

1. 检查是否存在嵌入式电子表格或 Sheet 卡片。带 A/B/C 列标、行号、内部滚动区域，或会打开电子表格视图的表格，都不能直接导出 Word。
2. 直接读取嵌入式电子表格的完整 used range、隐藏或可滚动的有效行列、合并区域和全部显示值，在原嵌入块旁创建同尺寸的飞书文档原生表格。公式按当前显示值写入。
3. 新表完成后逐行逐列比较行数、列数、每个单元格、合并区域、单位、表题、表注、来源和阅读顺序。校验全部通过后再删除原嵌入块；校验失败时保留原嵌入块并报告差异。
4. 能导出 Word 时执行测试导出并确认表格完整。只转移可见区域、漏掉隐藏或滚动区域、未经逐格校验，均视为不合格。
5. 不要把这项常规转换交给作者手工完成。如果直接 API 不能操作，可使用已授权的可控飞书界面；两条路径都不可用时，保留原块并报告准确阻塞原因。
6. 如果你只能看到粘贴后的纯文本，仍可完成文字终检和中英文空格规范，但无法自动转换来源嵌入块。必须写“受阻：需要飞书原文链接或可控页面”，不能声称已经通过。

四、排版备注

记录是否存在特殊要求，例如：文章不需要引言、手画图需要套海外独角兽模板、图片或表格需要特殊处理、发布时间不是默认时间。没有信息时不要自行猜测，请提醒作者确认。

五、放行规则

只有当文字终检、专有名词、中英文空格、标题层级、列表层级、飞书原生表格和排版备注全部确认完成，并且文章已是最终定稿时，才能写“可以 @排版”。只要有一项未确认或需要作者修改，就必须写“暂不建议 @排版”。

请严格按下面的格式输出：

终检状态：可以 @排版 / 暂不建议 @排版

已自动修正：
- 列出修正内容；只有能够准确统计时才写数量，没有则写“无”。

作者需处理：
- 逐项写明位置、问题、规则和建议动作；没有则写“无”。

飞书表格：
- 发现数量：
- 已转换数量：
- 行列与逐格校验：
- 原嵌入块删除状态：
- Word 测试导出：
- 阻塞项：无 / 具体说明

排版备注：
- 列出已确认的特殊要求；没有则写“无”；尚未确认则提醒作者确认。

修正后全文：
【输出完整文章，不要省略】

以下是需要终检的文章：

【粘贴全文或提供飞书文档】
```
