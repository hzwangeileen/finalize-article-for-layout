# finalize-article-for-layout

一套用于微信公众号文章排版前终检的 Codex Skill。它负责处理可安全自动化的文字与格式问题，检查需要作者决策的结构问题，并将飞书嵌入式电子表格转换为可完整导出 Word 的飞书原生表格。

## 能做什么

- 修正明确的错别字、漏字、重复字、重复空格和明显标点问题。
- 统一专有名词及英文缩写的大小写，例如 `OpenAI`、`OAI`。
- 在普通正文中自动规范中英文之间的半角空格。
- 将中文正文中的标点统一为全角形式，同时保护网址、邮箱、代码、公式和文件名。
- 根据语义处理 AI 写作中常见的破折号。
- 清理 bullet point、单个词和短语上的过度加粗，只保留真正需要强调的完整句子。
- 检查标题是否超过三个层次、标题是否跳级，以及 bullet point 和有序列表是否出现嵌套。
- 自动读取飞书嵌入式电子表格的完整数据，将其替换为飞书文档原生表格，并在校验通过后删除原嵌入块。
- 在条件允许时测试导出 Word，确认表格没有缺行、缺列或截断。
- 根据终检结果给出 `可以 @排版` 或 `暂不建议 @排版` 的明确结论。

## 不会做什么

这是格式终检 Skill，不是文章改写或发布工具。它不会：

- 替作者重写观点、论证、摘要或引言。
- 擅自调整标题层级、章节顺序、段落位置或列表从属关系。
- 收集发布时间、图片模板、是否需要引言等排版特殊要求。
- 在无法确认专有名词或句意时猜测修改。
- 在表格尚未完整读取和逐格校验时声称转换成功。

涉及文章结构或内容判断的问题会被准确标出，并交由作者修改。

## 推荐工作流

```text
文章定稿
→ 使用本 Skill 完成 proofreading 与格式规范
→ 作者处理 Skill 标出的结构问题
→ 重新运行终检
→ 可以 @排版
```

## 使用方式

向 Codex 提供飞书文档链接：

```text
Use $finalize-article-for-layout 修改并终检这篇文章：
https://example.feishu.cn/docx/xxxxxxxx
```

也可以直接粘贴文章全文：

```text
Use $finalize-article-for-layout 终检下面这篇文章，并输出修正后全文：

【文章全文】
```

直接粘贴文本时可以完成文字与结构终检，但无法读取或替换原飞书文档中的嵌入式表格。表格自动转换需要飞书原文链接、相应访问权限或可控的飞书页面。

## 输出内容

每次运行都会返回：

1. `终检状态`：`可以 @排版` 或 `暂不建议 @排版`。
2. `已自动修正`：已经完成的机械修改。
3. `作者需处理`：需要作者判断的具体位置、问题、规则和建议动作。
4. `飞书表格`：发现及转换数量、逐格校验、原嵌入块删除状态和 Word 导出结果。
5. `修正后全文`：仅在输入为粘贴文本或用户明确要求时提供。

## 核心放行规则

只有文字终检、专有名词、中英文空格、标题与列表层级、飞书原生表格及定稿状态全部通过，Skill 才会输出 `可以 @排版`。任何一项仍需确认时，都会输出 `暂不建议 @排版`。

## 安装

```bash
npx skills add https://github.com/hzwangeileen/finalize-article-for-layout
```

安装完成后即可通过 `$finalize-article-for-layout` 调用。
